# Zeitzonen-Umrechner

Ein bewusst reduzierter Zeitzonen-Umrechner zur Planung internationaler Zeiten.
Statt mehrere technische Zeitangaben anzuzeigen, liefert das Tool eine klare Aussage
in der lokalen Zeitzone.

## Funktionen

- 50+ Zeitzonenkürzel (CET, PST, EST, JST, GMT, etc.)
- Alphabetisch sortierte Dropdowns
- Explizite Ziel-Datums- und Uhrzeiteingabe
- Klar formuliertes Ergebnis in der lokalen Zeitzone
- Metallic-Layout als Standard
- Optionales Flat-Layout
- Persistente Layout-Präferenz (lokal gespeichert)
- Responsives Design
- Keine Abhängigkeiten
- Offline nutzbar

## Anwendungsfälle

- "Meeting um 22:00 UTC – wann ist das für mich?"
- Planung internationaler Meetings
- Überprüfung von Einladungen
- Vergleich zukünftiger Termine

## Installation

Repository herunterladen oder klonen und `timezone-converter.html` im Browser öffnen.

## Verwendung

1. Eigene Zeitzone wählen
2. Ziel-Zeitzone wählen
3. Gewünschtes Ziel-Datum & Uhrzeit eingeben
4. Convert klicken
5. Ergebnis als klare Aussage lesen

## Layout-Stile

- Metallic (Standard): hochwertig, app-artig
- Normal: schlicht, flach

Die Auswahl wird lokal im Browser gespeichert.

## Technische Details

- HTML5
- CSS3
- Vanilla JavaScript
- Intl.DateTimeFormat API
- IANA-Zeitzonendatenbank
- LocalStorage nur für UI-Einstellungen
